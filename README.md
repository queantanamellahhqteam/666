# Freemasonry

Tovuti ya elimu ya Kiswahili na English kuhusu Freemasonry. Si tovuti rasmi ya Grand Lodge yoyote.

## Ndani yake kuna nini

- Logo inayojichora: Square (V), Compasses (^), herufi G, kisha jina.
- Tabaka nne za ndani: Freemasonry ni nini, Utajiri, Sheria zake, Jinsi ya kujiunga.
- Kitufe cha kuchagua lugha (Kiswahili / English) juu ya kila ukurasa.
- Chini kabisa: © 2026 Freemason.

## Faili

| Faili | Kazi |
| --- | --- |
| `index.html` | Maudhui yote ya tovuti (Kiswahili na English) |
| `style.css` | Muonekano na rangi |

| `favicon.svg` | Alama ndogo kwenye kichupo cha kivinjari |

## Jinsi ya kuiweka kwenye GitHub Pages

1. Ingia kwenye GitHub, bonyeza **New repository**, na uipe jina (mfano `freemasonry`). Iwe **Public**.
2. Bonyeza **Add file** > **Upload files**, kisha pakia faili zote nne hapo juu pamoja na `README.md`. Bonyeza **Commit changes**.
3. Nenda **Settings** > **Pages**.
4. Chini ya **Build and deployment**, chagua **Deploy from a branch**. Chagua branch `main` na folder `/ (root)`, kisha bonyeza **Save**.
5. Subiri dakika 1 hadi 2. Link ya tovuti yako itakuwa:

   `https://JINA-LAKO.github.io/freemasonry/`

   (badilisha `JINA-LAKO` na jina lako la GitHub, na `freemasonry` na jina la repository uliyochagua).

## Kujaribu kwenye kompyuta

Fungua `index.html` kwenye kivinjari. Hakuna kitu cha kusakinisha.

## Kubadilisha vitu

- **Jina la hakimiliki:** tafuta `© 2026 Freemason` ndani ya `index.html` (inajirudia kila tabaka).
- **Maandishi:** kila sentensi ina matoleo mawili, `class="sw"` (Kiswahili) na `class="en"` (English). Badilisha yote mawili.
- **Rangi za tabaka:** angalia `.l0` hadi `.l4` ndani ya `style.css`.
- **Muda wa logo:** angalia sehemu ya `Layer 0` ndani ya `style.css`. Namba `4400` ndani ya `script.js` ni muda (milisekunde) kabla kitufe cha **Ingia** hakijaonekana.
